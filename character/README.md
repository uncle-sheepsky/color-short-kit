# character/ — 여기에 원하는 캐릭터를 넣으세요

이 템플릿은 **여기 넣은 캐릭터로 영상을 만듭니다.** 동작 하나 = 폴더 하나.

```
character/
  wave/   00.png 01.png 02.png …   (손 흔들기 — 장 순서대로 재생)
  happy/  00.png 01.png …
  surprise/ 00.png …
```

- 투명 바탕 PNG(또는 WEBP) · 모든 장은 같은 캔버스 크기 · 캐릭터가 캔버스 아래쪽까지 닿아 있으면 화면 아래에 붙어 서 있는 구도가 됩니다.
- 동작은 2개 이상, 6~12개면 장면이 다양해집니다. 한 동작은 1장(정지)이어도 됩니다.
- 색은 그림에서 자동으로 뽑습니다: 선이 진하고 몸에 뚜렷한 색 2~3가지가 있으면 「색이 하나씩 돌아오는」 연출이 잘 삽니다.
- 장 사이 시간은 `config.json` 의 `frame_ms`(기본 100ms).
